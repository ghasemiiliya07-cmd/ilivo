# ilivo v4 final

نسخه نهایی ilivo با پنجره شروع پروژه و تصاویر نمونه‌کار محلی.

## تصاویر نمونه‌کار
چهار تصویر نمونه‌کار همان تصاویر استفاده‌شده در طرح قبلی هستند و داخل `public/portfolio` قرار گرفته‌اند.

## اجرا
```bash
npm install
npm run dev
```
سپس `http://localhost:3000` را باز کنید.

دکمه شروع پروژه، نام + نوع سایت + بودجه را می‌گیرد و با یک کلیک پیام آماده را به واتساپ 09122971546 می‌فرستد.
